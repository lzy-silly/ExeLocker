# ExeLocker - 文件/文件夹权限锁定工具

一个基于 Python + tkinter 的 Windows 小工具，用于通过 NTFS ACL 权限控制，**彻底禁止指定 EXE 文件或整个文件夹被其他程序读取、写入、执行**。

## ✨ 功能特性

- 🔒 **文件锁定模式** - 锁定单个 EXE 文件，禁止读/写/执行
- 📁 **文件夹递归锁定模式** - 一键锁定文件夹及其所有子文件、子文件夹
- 🔓 **一键解除** - 移除之前添加的拒绝规则，恢复正常权限
- 👁 **状态实时检测** - 自动显示当前目标是否已被锁定
- 📝 **操作日志** - 详细记录每次操作结果
- ⬆️ **自动 UAC 提升** - 非管理员启动时自动请求管理员权限
- 📦 **单文件发布** - 打包后无需 Python 环境即可运行

## 🎯 适用场景

- 防止流氓软件自动下载更新包覆盖原程序
- 防止特定程序被误删除或修改
- 临时禁止某个程序运行（比重命名/移动更优雅）
- 保护重要文件夹不被其他程序读写

## 🛠 原理说明

使用 Windows NTFS ACL（访问控制列表）机制，向目标文件/文件夹的 DACL（自主访问控制列表）中添加一条 **ACE（访问控制条目）**：

- **类型**：`ACCESS_DENIED_ACE_TYPE`（拒绝访问）
- **主体**：`Everyone`（S-1-1-0，所有用户包括 SYSTEM、Administrators）
- **权限**：`FILE_GENERIC_READ | FILE_GENERIC_WRITE | FILE_GENERIC_EXECUTE`
- **仅拒绝这三项**，不影响列出目录、删除、修改权限等其他操作

> ⚠️ **注意**：因为拒绝 `Everyone`，连管理员和 SYSTEM 也会被拒绝。解锁时只需移除这条 ACE 即可恢复。

## 📋 使用方法

### 直接运行（需 Python 环境）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 以管理员身份运行
python main.py
```

### 打包为单文件 EXE（推荐）

```bash
# 1. 安装 pyinstaller
pip install pyinstaller

# 2. 运行打包脚本
build.bat

# 3. 成品在 dist/ExeLocker.exe
# 右键 → "以管理员身份运行"
```

## 🖥 界面说明

| 区域 | 说明 |
|------|------|
| 目标路径 | 输入或选择要锁定的文件/文件夹路径 |
| 选择文件 | 打开文件对话框，默认过滤 `.exe` |
| 选择文件夹 | 打开文件夹选择对话框 |
| 锁定模式 | 单选：文件模式 / 文件夹递归模式 |
| 🔒 锁定按钮 | 执行锁定，拒绝读/写/执行 |
| 🔓 解除按钮 | 移除锁定，恢复正常权限 |
| 目标状态 | 实时显示：🔒 已锁定 / 🔓 未锁定 / 路径不存在 |
| 操作日志 | 记录每次操作的详细结果 |

## ⚠️ 重要提醒

1. **必须以管理员权限运行**，否则修改 ACL 会失败（程序会自动请求 UAC 提升）
2. **锁定后该文件/文件夹将无法被任何程序读取、写入、执行**，包括资源管理器预览、杀毒扫描、备份软件等
3. **文件夹模式会递归处理所有子项**，大文件夹可能需要较长时间
4. **如果目标文件正在运行**，锁定可能会失败，请先关闭该程序
5. **卸载/更新软件前请先解锁**，否则安装程序无法覆盖文件

## 🔧 故障排除

| 问题 | 解决方法 |
|------|----------|
| 提示"权限不足" | 确保以管理员身份运行 |
| 锁定后无法解锁 | 以管理员运行本工具再次点击解除 |
| 杀毒软件报毒 | 属于修改系统权限的正常行为，加入白名单即可 |
| 文件夹锁定部分失败 | 通常是文件被占用，关闭相关程序后重试 |
